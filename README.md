# MedVault — Healthcare Management System

MedVault is a full‑stack healthcare management system designed to streamline patient records, appointments, authentication, and admin workflows. It integrates a **Spring Boot backend** with a **React-based frontend**, offering a secure and scalable solution for healthcare applications.

---

## 🚀 Features

* Secure user authentication and authorization
* Patient record management
* Appointment scheduling
* Admin dashboard
* RESTful API services
* Modular and scalable backend architecture
* Responsive React UI

---

## 🛠️ Tech Stack

### **Frontend**

* React.js

## ⚙️ Setup Instructions

### **1️⃣ Clone the Repository**

```
git clone <repo-link>
cd MedVault---Healthcare-Management-System
```

### **2️⃣ Backend Setup (Spring Boot)**

```
cd backend
mvn install
mvn spring-boot:run
```

Backend runs at: **[http://localhost:8080](http://localhost:8080)**

### **3️⃣ Frontend Setup (React)**

```
cd frontend
npm install
npm start
```

Frontend runs at: **[http://localhost:3000](http://localhost:3000)**

---

Create `.env` files for frontend & backend as needed (e.g., API URLs, DB credentials).
